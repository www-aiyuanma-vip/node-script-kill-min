## 迷雾剧本杀

本项目是面向剧本杀实体门店的「组局预约」业务系统，品牌演示名为「迷雾剧本馆」。整体由三端协同：玩家通过微信小程序浏览剧本、报名拼车、管理钱包与评价；门店管理员或工作人员通过 Web 管理后台排期开局、核销名单、维护门店与内容；两端共用同一套后端服务与 MySQL 业务库。支付为门店实务中的虚拟钱包与到店付流程，不对接真实微信支付通道，便于课堂演示完整闭环。

### 玩家端（微信小程序）

底部四个主入口：首页、剧本、组局、我的。登录后可预约；未登录可浏览公开内容，涉及报名与资产操作时引导至登录页。

**首页**  
全屏轮播展示门店运营配置的宣传图，叠加品牌主视觉与一句导语。提供「报名拼车」「浏览剧本」「门店公告」三条主路径，把玩家快速导向组局列表、剧本库或公告列表。

**剧本库与剧本详情**  
剧本列表按门店上架的剧本展示封面、题材、难度、人数与价格等信息，支持进入详情。详情页包含封面与标签、价格与订金、剧本简介；下方列出该剧本近期可报名场次及人数进度，可直接跳转报名；另展示其他玩家对该剧本的评分与文字评价，便于选本决策。

**组局（场次列表）**  
展示门店排期、处于招募中的场次（含已满员仍可见的场次，便于了解热度）。每条显示剧本、开场时间、门店与包间、状态文案与人数进度（已报/上限、还差几人）。场次仅由门店后台创建，玩家不能自行开局；页面明确提示「个人不能开局」。可报名场次进入确认页，不可报名则按钮置灰并给出原因文案。

**确认报名**  
汇总场次信息（剧本、时间、门店、房间、进度、价格与订金）与当前玩家资料（昵称、手机、钱包余额）。支付方式二选一：到店付（到场再结全款）、钱包订金（从虚拟钱包预扣订金）。提交后生成预约记录，可在「我的场次」中查看。

**我的**  
已登录展示头像、昵称与钱包余额入口；未登录展示灰色默认头像与登录引导。菜单包含：我的场次、钱包、评价、反馈、资料、去组局等。

**我的场次（报名订单列表与详情）**  
列表按玩家自己的预约展示状态与关键场次信息，可进入详情。详情展示报名状态、场次信息（剧本、开场时间、房间号、门店、场次状态）、支付信息（订单号、支付方式、支付状态、订金金额）及取消规则说明。玩家可在规则允许时取消报名。场次完成后且已核销到场时，可对剧本与门店分别打星并填写文字评价；已评价则只读展示星级与内容，避免重复提交。

**钱包与充值**  
展示当前余额及用途说明（支付场次订金），下方为钱包流水（充值、扣订金、退款等变动类型、时间与金额）。充值页支持选择或输入金额进行虚拟充值，便于演示订金冻结与退还。

**门店公告**  
公告列表与公告详情，展示门店发布的通知标题与正文，供玩家了解活动、规则或营业信息。

**个人资料**  
维护昵称、手机等资料，支持上传自定义头像；未设置时使用统一灰色默认头像。资料用于报名确认页展示与门店联系。

**登录**  
采用微信授权登录对接后端会话。需配置真实小程序应用标识后方可完成正式登录；账号状态异常时不可继续业务操作。

**评价列表**  
汇总玩家已提交的评价记录，便于回顾历史评分。

**意见反馈**  
玩家提交文字反馈，供门店在后台查阅与处理。

**开局提示页**  
若误入个人开局相关入口，仅提示「场次由门店排期」，并引导前往组局页报名，强化「玩家拼车、门店排期」的业务规则。

### 管理端（Web 后台）

工作人员账号登录后进入左侧菜单驱动的业务工作台。菜单与权限由系统管理模块配置，不同角色可见菜单可不同。

**工作台**  
展示运营概览数据（如场次、报名、玩家等统计）、待办类指标，以及近几日场次趋势、场次状态分布、报名趋势、剧本题材分布、热门剧本、开场时段等图表，帮助门店快速掌握经营情况。

**门店资料**  
维护门店基础信息（名称、地址、联系方式、营业说明等），作为小程序展示与场次归属的基础。

**包间管理**  
维护门店包间名称、容量与状态，排期时可选绑定包间。

**剧本管理**  
维护剧本库：封面、标题、题材、难度、人数区间、时长、价格、订金、简介与上架状态等，供小程序剧本库与排期选用。

**场次管理**  
门店排期核心模块。可新增、编辑场次（选择门店、剧本、包间、房间号、开场/结束时间、最少/最多人数、价格等）。支持查看报名名单。场次状态流转覆盖实务常见环节：招募中、满员、确认开场、完成、取消、流局等。确认开场后可对名单核销；完成场次需在开场时间到达之后，避免未开场却完结导致订金处理失真；流局或取消时按规则处理已付订金退还。

**预约名单**  
按预约维度查看玩家报名记录，支持按场次或状态筛选，配合到店核销、未到标记等运营操作，与场次名单联动。

**玩家用户**  
查看小程序注册玩家资料、账号状态与钱包相关信息，支持运营侧必要维护（如状态调整），表格全宽展示便于查阅。

**轮播管理**  
维护小程序首页轮播图及排序、启用状态。

**公告管理**  
发布与编辑门店公告，控制对小程序侧的可见内容。

**评价管理**  
查看玩家对剧本与门店的评分与文字评价，便于质检与选本参考。

**意见反馈**  
查阅玩家提交的反馈内容与处理情况。

**系统管理**  
含个人中心、用户管理、角色管理、菜单管理：维护后台账号、角色权限与侧边菜单结构，支撑多角色协作（如管理员与工作人员）。

### 后端与数据层（支撑能力，无独立界面）

统一提供小程序与管理后台接口：鉴权登录、剧本与场次查询、报名与取消、钱包充值与流水、评价与反馈、门店运营资源的增删改查，以及静态图片访问。首次启动可按规则自动检测并导入演示数据库（库已存在且已初始化则跳过，避免覆盖学生本地数据）。业务上强调：场次由门店创建；报名可选到店付或钱包订金；满员场次仍可在列表展示；核销与完成、流局退款等状态与资金变动保持一致。
